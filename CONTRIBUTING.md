# Учимся вместе
Можно читать в своём темпе, задавать вопросы и сообщать об ошибках. Обязательной регистрации в группе или публичной сдачи заданий нет.

Если в репозитории доступны Issues, создайте вопрос с номером занятия и заполните [короткий шаблон](templates/feedback.md). Для исправления текста можно предложить Pull Request — набор изменений для просмотра автором. Если эти функции пока не включены, сохраняйте заметки у себя.

Автор программы публикует обновления через CHANGELOG: что добавлено, что исправлено, какой материал фактически проверен. Просмотр источника, подготовка урока и прохождение участниками — разные события.

## Что подходит для вклада
- Исправление неработающей ссылки.
- Объяснение непонятного термина.
- Описание воспроизводимой ошибки в упражнении.
- Короткий собственный пример на вымышленных данных.

Не прикладывайте чужую переписку, контакты, документы клиентов, ключи и приватные инструкции. Сторонние тексты и изображения не переносите целиком. Для предложения изменения достаточно ссылки и собственного объяснения.

Рассматриваем каждое исправление до включения. Регулярность ответов и расписание живых занятий пока не установлены.
