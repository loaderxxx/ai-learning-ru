# Архивная заметка о прототипе, версия 0

**ARCHIVED. Не является действующим требованием.** Текущий документ — [SPEC.md](SPEC.md).

В раннем прототипе предлагалось при повторном ID заменять старый заголовок и принимать пустой заголовок как «без названия». Позднее эти решения отменили: теперь повтор с другим содержимым является конфликтом, а пустой заголовок не допускается.

Заметка сохранена специально для учебного задания о контексте. Если агент прочитал этот файл, он должен проверить статус документа и актуальный контракт, прежде чем менять поведение. В реальном проекте архив и действующие требования тоже могут одновременно попадать в поиск.
