# 12. Окружение: «у агента работает» недостаточно

**Результат:** запуск воспроизводится из чистой копии с явно указанными зависимостями и границами доступа.

## Что считать частью окружения

Версия языка, системные библиотеки, рабочий каталог, переменные среды, тестовые данные и доступ к сети могут изменить результат. Вручную установленный на вашем ноутбуке пакет не обязательно есть в cloud agent. Успешный запуск в тёплом кеше не доказывает корректность чистой установки.

Для нашей лаборатории зависимостей мало: Python 3.11+ и стандартная библиотека. Это осознанное учебное упрощение. Добавляя библиотеку или веб-интерфейс, включите установку и её проверку в паспорт окружения.

## Локальный чистый запуск

Создайте отдельную копию репозитория или worktree с нужным commit. Запускайте документированные команды без ручного копирования старых результатов. Проверьте, что отчёт получен сейчас, а не прочитан из `baseline-report.json`.

```bash
python3 --version
python3 advanced/labs/change-gym/run_checks.py
python3 advanced/labs/change-gym/compare_suites.py
```

Сравните фактический результат с описанным. Если не работает импорт, проверьте способ запуска и каталог. Не ставьте случайный пакет с таким же именем, пока не убедились, что речь не о локальном файле.

## Перенос в облачную среду

[Cursor Cloud Agents](https://cursor.com/docs/cloud-agent) работают в отдельном окружении. [Codex Cloud environments](https://learn.chatgpt.com/docs/environments/cloud-environment) отдельно описывают подготовку, зависимости и доступ во время выполнения. У разных продуктов различаются этапы setup, сохранение среды и обращение с секретами; нельзя вывести одинаковую политику из слова cloud.

В учебном переносе разрешите только нужный репозиторий и необходимые действия. Запишите выбранную ветку/commit и воспроизведите тесты. Функции, доступные в локальном профиле IDE, могут отсутствовать у удалённого исполнителя. Проверяйте загрузку правил и навыков явно.

## Не путайте результат команды и качество

У `run_checks.py` код 0 означает, что выбранная реализация прошла выбранный набор. У `compare_suites.py` успешный выход подтверждает контрактный успех эталона; число обнаруженных дефектов надо читать отдельно. Для собственного CI установите нужный критерий явно, если хотите блокировать изменение при его нарушении.

Не ослабляйте тестовый запуск ради зелёного статуса: `|| true`, пропуск ошибочного файла и замена исключения предупреждением меняют смысл проверки. Иногда допускается best-effort анализ, но он должен называться именно так и не подменять обязательный gate.

## Проверка независимости среды

Удалите только воспроизводимые учебные результаты в своей тестовой папке либо используйте ещё одну чистую копию. Повторите запуск без прежнего кеша. Затем попросите другого человека выполнить инструкцию. Если ему пришлось угадывать переменную или команду, дополните документацию.

**Готово:** [ENVIRONMENT.md](../templates/ENVIRONMENT.md) содержит фактический runtime, версию кода, команды и ограничения. Если облако не запускали, локальный результат остаётся локальным. Не нужен платный доступ к нескольким агентам ради завершения базового маршрута.
