# Если вы застряли

Сначала сохраните точную команду, фактическое сообщение и версию кода. Не отправляйте полный дамп среды или ключи. Вопрос через [Issues](https://github.com/loaderxxx/ai-learning-ru/issues/new) публичный.

| Симптом | Первая проверка | Следующее действие |
|---|---|---|
| `python3` не найден | Какая команда Python установлена: `python`, `py` | Указать её вместо `python3`; нужен runtime 3.11+ |
| Файл не найден | Вы в корне распакованного/клонированного репозитория? | Проверить путь; просмотр GitHub не является скачиванием |
| `ModuleNotFoundError` для job_store/checks | Запускаете ли именно поставленный script по инструкции? | Не устанавливать одноимённый пакет; проверить наличие соседних файлов |
| Контрактный тест мутанта падает | Выбран ли `--variant`, отличный от reference? | Это ожидаемое обнаружение учебной ошибки |
| Эталон не проходит | Версия Python, изменения локальных файлов, точный тест | Сравнить с чистой копией, не стирать свою работу |
| `compare_suites` завершился успешно, но есть ошибки | Это отчёт по дефектным вариантам? | Прочитать поля результатов; ошибки мутантов ожидаемы |
| Агент использует старое правило | Какой документ он прочитал и какой у него статус? | Дать актуальную спецификацию и явную ссылку на заменённое правило |
| Cursor не применяет настройку | Корень проекта, `.mdc`, frontmatter, glob, версия | Создать правило через интерфейс и проверить scope |
| ChatGPT не видит новый код | Код приложен снимком или доступен через папку/подключение? | Передать актуальные файлы и указать версию |
| Worktree не создаётся | Имя ветки/папки уже занято или ветка уже используется? | Выбрать новое имя; не обходить ошибку через force |
| Локальный запуск есть, cloud падает | Зависимости, каталог, сеть, setup, доступность файлов | Сравнить паспорта двух сред |
| Модель «проверила» без команды | Есть ли в её среде исполнение? | Попросить фактический вывод или самостоятельно выполнить команду |
| Review содержит расплывчатые замечания | Есть ли вход и нарушенное требование? | Попросить минимальное воспроизведение |

## Как задать полезный вопрос

Напишите: модуль, ожидаемый результат, точная команда, фактический результат, runtime и изменение, которое уже пробовали. Приложите минимальный синтетический пример. Для ошибки в объяснении укажите фрагмент и официальный источник.

Если функция продукта недоступна в вашем аккаунте, это не означает, что вы неправильно проходите курс. Выполните локальный вариант и отметьте интеграционный шаг непроверенным. Тарифы и интерфейсы не зафиксированы навсегда в учебном тексте.
