# Шаблоны

Берите один под текущую задачу. Заполнение всех файлов не является обязательной бюрократической ступенью.

| Шаблон | Когда нужен |
|---|---|
| [RUN.md](RUN.md) | Паспорт запуска |
| [ENVIRONMENT.md](ENVIRONMENT.md) | Паспорт окружения |
| [CONTEXT.md](CONTEXT.md) | Контекст одной задачи |
| [CHANGE.md](CHANGE.md) | Спецификация изменения |
| [DECISION.md](DECISION.md) | Инженерное решение |
| [HANDOFF.md](HANDOFF.md) | Передача и продолжение задачи |
| [REVIEW.md](REVIEW.md) | Review конкретной версии |
| [EXPERIMENT.md](EXPERIMENT.md) | Сравнение способов работы |

Незаполненное поле — неизвестное, а не повод придумывать факт. Не переносите в публичные отчёты ключи, персональные данные или чужую закрытую переписку.
