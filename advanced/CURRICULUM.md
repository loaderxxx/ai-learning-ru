# Программа и критерии продвижения

Предпосылки: вы читаете код, пользуетесь Git и терминалом, уже делали правки с ИИ. Для лаборатории достаточно Python 3.11+. Если пока трудно отличить API, retrieval и tool calling, используйте соответствующие главы [предыдущего маршрута](../developers/README.md).

## Пять блоков

| Блок | Модули | Проверяемый результат |
|---|---|---|
| Контекст и намерение | 00–04 | Вы передаёте одну задачу между инструментами без потери требований |
| Доказательства | 05–08 | Находите причину ошибки, проверяете тест, принимаете безопасную правку |
| Продолжение и разделение | 09–10 | Новый сеанс/исполнитель продолжает работу по сохранённым данным |
| Инструменты и среда | 11–13 | Различаете возможности агента, настройки и фактически проверенную интеграцию |
| Результат и цена | 14–15 | Показываете законченный проект и честный отчёт о затратах |

## Три режима прохождения

**Быстрый вечер:** 00 → 06 → 07. Запустить демонстрацию, написать один независимый тест, проверить одно замечание. Ориентир 2–3 часа.

**Основной:** 00–10, локальная часть 12, затем 14–15. Ориентир 25–40 часов. Применяйте доступный AI-инструмент; перенос между двумя продуктами проверяйте только при наличии обоих.

**Расширения:** установка конкретного skill/hook/MCP, cloud agent и UI. Добавляйте их по необходимости. Оценка 10–20 часов сильно зависит от выбранного стека. Наличие текста задания не означает готовую интеграцию.

## Как отмечать прогресс

- Прочитано: можете объяснить идею и ограничение.
- Воспроизведено: команда выполнена в вашей среде, результат сохранён.
- Применено: новое условие обработано без поломки старого договора.
- Проверено другим: другой человек повторил запуск и рассмотрел доказательства.

Самопроверка допустима, но не заменяет последний статус. Не отмечайте облачный запуск по локальному результату или review по обещанию агента.

## Что сдавать

Одно изменение, его требования и diff, фактические проверки, найденный тестом дефект, handoff и описание ограничений. Для оценки работы с ИИ добавьте инструмент/режим, краткий пример взаимодействия и время до принятого результата. Не выгружайте весь чат или секреты окружения.

Не нужен идеальный балл по всем темам. Нужно понимать, на каком уровне находится конкретный результат. [Итоговый проект](modules/15-capstone.md) задаёт полный комплект.
