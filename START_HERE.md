# Начать за 15 минут
1. Создайте у себя папку «Моя практика с ИИ» или заметку с таким названием.
2. Скопируйте [учебный текст](practice/meeting.md). Все обстоятельства в нём вымышлены.
3. Выберите доступный инструмент. Для текстовой практики достаточно одного чата. Не создавайте платные подписки только ради этой программы.
4. Откройте [первое занятие](lessons/00-basics.md).
5. Сохраните свой запрос, ответ и одну замеченную ошибку либо подтверждение, что условия соблюдены.

Для работы с файлами в Cursor установите приложение через [официальный Quickstart](https://cursor.com/docs/get-started/quickstart), войдите в свой аккаунт и откройте отдельную учебную папку. Не открывайте папку с личными или рабочими документами для первого упражнения.

## Если GitHub незнаком
README — главная страница. Нажимайте на названия файлов и ссылки; команды не нужны. Дневник можно вести в обычных заметках. Для вопроса через Issues нужен аккаунт GitHub; участие в обсуждении необязательно. Если репозиторий скачан архивом, распакуйте его и открывайте файлы .md как обычный текст.

## Если нет компьютера или доступа
Занятия 1–2 требуют Cursor на компьютере. Их можно временно пропустить и вернуться позднее. Текстовые занятия выполняйте в доступном вам сервисе; если Claude недоступен, сделайте упражнение в другом чате и укажите замену в дневнике. Это не считается практикой именно в Claude.

## Что публиковать
Делиться можно только учебными примерами без персональных данных: номер занятия, свой запрос, короткий результат, что пришлось исправить. Полный чат, контакты, документы клиентов и сведения аккаунта публиковать не нужно.

Наша отметка «задание выполнено» не является сертификатом производителя. Полные курсы и их условия находятся на официальных платформах.
