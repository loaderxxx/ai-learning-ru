# Словарь и типовые затруднения

[English](TROUBLESHOOTING.en.md) · [Карта](README.md)

## Сначала различайте понятия

| Термин | Что это значит в этом курсе |
|---|---|
| Model / LLM | Компонент, создающий ответ по входному контексту; не весь продукт |
| API / SDK | Интерфейс сервиса / клиентская библиотека для обращения к нему |
| Adapter | Переводчик между внутренним контрактом и конкретным API |
| Routing | Правило выбора обработчика или модели |
| Fallback | Разрешённое запасное действие после определённого сбоя |
| Tool calling | Модель предлагает вызов; приложение проверяет и выполняет |
| Workflow / orchestration | Управление последовательностью, состоянием и условиями перехода |
| Agent | Компонент с модельным выбором шагов внутри программных ограничений |
| MCP | Протокол подключения возможностей; не разрешение и не модель |
| Retrieval / RAG | Поиск контекста / использование найденного при генерации |
| Embedding | Числовое представление для задач сходства и других операций |
| Eval | Проверка поведения AI на наборе задач по заданным критериям |
| Idempotency | Повтор одного намерения не создаёт дополнительный предусмотренный эффект |
| Trace | Связь событий и операций одного запроса |
| Mock | Программная подмена зависимости, а не доказательство её реальной работы |
| Baseline | Исходный вариант, относительно которого измеряем изменение |
| Held-out | Отложенные примеры, не использованные для подгонки выбранного варианта |

## Диагностируйте, прежде чем переписывать

| Симптом | Что проверить первым | Как подтвердить исправление |
|---|---|---|
| Python не найден | Имя команды и установленную версию | Команда версии и один тест |
| Тесты не находятся | Рабочую папку и `-s ai-in-code/lab` | Runner показывает ожидаемые тесты, не «0 tests» |
| API отказывает в доступе | Правильный аккаунт, разрешение модели и конфигурацию ключа | Один разрешённый синтетический live-вызов, без публикации ключа |
| Постоянный timeout | Сеть, модель, общий deadline и вложенные retries | Ограниченное время завершения, лог попыток |
| JSON корректен, ответ неверен | Разметку, исходные данные и семантическую проверку | Тест факта, а не только JSON parser |
| Модель предлагает tool, но ничего не происходит | Диспетчер и возврат результата с call ID | Полный round trip и событие `tool_completed` |
| Возникает бесконечный цикл | Терминальные условия и счётчики | Искусственный цикл завершается по лимиту |
| Fallback раскрывает запрещённые данные | Проверку допустимости provider до отправки | Заблокированный маршрут не получает запрос |
| Дублируются записи | Транзакцию, idempotency key, конкурентные запросы | Один эффект после повтора и restart |
| RAG цитирует старую цену | Версии, статус документа, индекс и кэш | Правильная версия и объяснимый конфликт |
| MCP не отвечает | SDK/протокол, stdout, handshake, timeout | Очищенный transcript discovery/call |
| Экономия не видна | Все попытки, judge/retrieval и неуспехи | Стоимость полного успешного задания |
| Утечка в логах | Raw prompts, исключения, headers, trace exporters | Тест с вымышленным секретом |
| Работает только у автора | Скрытую конфигурацию и незаписанные зависимости | Чистая установка другим человеком |

## Как задать хороший вопрос

Укажите этап, цель, команду, версию, минимальный синтетический вход, ожидаемый и фактический результат. Приложите очищенный traceback или event ID. Не публикуйте ключи, документы клиента или весь приватный чат. Сначала локализуйте слой: ввод, адаптер, модель, retrieval, tool, workflow или интерфейс.

Один полезный запрос AI-наставнику: «Объясни причину этой ошибки на минимальном примере. Не переписывай проект целиком. Предложи тест, который отличит две возможные причины». После подсказки самостоятельно объясните исправление и запустите негативный случай.
