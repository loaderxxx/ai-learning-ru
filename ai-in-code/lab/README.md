**Стенд работает без API-ключей, сторонних пакетов и сетевых запросов. Это mock-демонстрация, а не подключённая нейросеть.** Исходники: [core.py](core.py), [test_core.py](test_core.py).

## Запуск с нуля

Нужны Git и Python 3.11+. В выпуске проверено на Python 3.13.5; другие версии отдельно не запускались. В Windows команда Python может называться `py`, в macOS/Linux — `python3`. Проверьте версию прежде, чем заменять команду.

```bash
git clone --branch work/chatgpt/20260928-ai-in-code --single-branch https://github.com/loaderxxx/ai-learning-ru.git
cd ai-learning-ru
python --version
python -m unittest discover -s ai-in-code/lab -p 'test_*.py' -v
python ai-in-code/lab/core.py
```

Если рабочая копия уже существует, не перезаписывайте свои изменения. Проверьте `git status`, сохраните работу и получите нужную ветку в отдельной папке/worktree. Пока материал находится в рабочей ветке, обычное скачивание `main` не содержит этот выпуск.

## Что вы увидите

Первая заглушка возвращает временную ошибку. Код переходит к разрешённой запасной заглушке. Та предлагает `calculate_total(250, 4)`, получает настоящий вычисленный результат `1000` и затем выдаёт заранее написанный финальный текст. В выводе: `mode: mock`, `status: answered`, `model: mock-backup`, `attempts: 3`, один `tool_completed`.

Первые две попытки — неуспешная основная и успешная запасная; третья — финальный ответ запасной. Текст результата прописан в сценарии, а не придуман моделью. Смена текста запроса сама по себе не меняет script: для учебного случая меняйте и заранее ожидаемый сценарий.

## Как читать код

`Model` задаёт минимальный интерфейс. `ScriptedModel` подменяет провайдера. `dispatch` ограничивает функции и аргументы. `run` связывает шаги, fallback, результаты tools и журнал. `seen` повторно использует результат одинакового call ID внутри одного запуска; это не долговременная идемпотентность.

Доступны два инструмента: точный расчёт в центах и поиск вымышленной записи по ID с проверкой tenant. Tenant передаётся доверенным приложением; сам стенд не реализует аутентификацию. Предельные размеры и количества — параметры учебного примера.

## Пробуйте последовательно

1. Измените количество с 4 на 5 и ожидаемый финальный текст. Получите 1250.
2. Подставьте `True` или строку вместо количества. Получите отказ контракта.
3. Запросите `beta-hours` от `alpha`. Убедитесь, что содержимое не выдаётся.
4. Повторите call ID с прежними и с изменёнными аргументами. Найдите отличие поведения.
5. Сделайте бесконечно выглядящий сценарий и уменьшите `max_steps`; найдите остановку.
6. Замените TransientError на AccessError. Убедитесь, что запасная модель не вызывается.

## Чего здесь нет

Нет живой LLM, HTTP-сервера, MCP, embeddings/RAG, database, SDK, сетевых deadline, streaming, persistent state, внешних write-tools или approvals. Финальный текст проверяется только по форме, не по фактам. Ограничение числа синхронных шагов не прерывает зависший внешний вызов; реальные timeout/cancellation реализуются на этапе 10. Логи не содержат сырые prompts, но итоговый ответ модели в реальном приложении потребует дополнительной проверки приватности.
