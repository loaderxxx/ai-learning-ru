# Рабочая тетрадь инженера: знания подтверждаются результатом

[English](WORKBOOK.en.md) · [Карта пути](README.md)

Храните свою тетрадь в собственном репозитории или заметках. В публичный учебный репозиторий не нужно загружать персональные данные, все чаты или результаты других людей. Достаточно коротких записей, позволяющих воспроизвести и объяснить работу.

## 1. Карточка одного этапа

```text
Этап / дата:
Какой навык тренирую:
Что уже умел до начала:
Что прочитал (точный раздел/ссылка):
Что сделал сам:
Где помог AI и что проверил после него:
Версия кода / commit:
Среда и зависимости:
Команда запуска:
Положительный случай / фактический результат:
Негативный случай / фактический результат:
Какое новое условие проверил:
Что пока не работает или не проверял:
Моё объяснение механизма в 3–5 предложениях:
Следующий шаг:
```

Не заполняйте пустое поле предположением. «Не запускал API» — корректная запись, а «API работает, потому что есть адаптер» — нет.

## 2. Паспорт настоящей интеграции

| Поле | Что записать |
|---|---|
| Компоненты | Клиент, сервер/provider, SDK и их версии |
| Модель | Точный ID из конфигурации и ответа; различайте заявленное и фактическое |
| Транспорт | HTTP/stdio/локальный процесс; endpoint без секретов |
| Режим | MOCK / CONTRACT TEST / LIVE VERIFIED / DESIGN ONLY / NOT RUN |
| Возможности | Фактически проверенные structured output, tools, streaming, MCP |
| Данные | Только синтетические или явно разрешённые; tenant и граница передачи |
| Ограничения | Timeout, общий deadline, max calls/steps, допустимый fallback |
| Доказательство | Команда, дата, очищенный transcript/result, версия кода |
| Ошибка | Один воспроизведённый отказ и реакция системы |
| Стоимость | Измеренный usage/расход или UNKNOWN; не подставляйте ноль |

API-ключ, токен и полные заголовки авторизации в паспорт не входят. Доступ в аккаунт проверяющего передавать не нужно.

## 3. Карточка архитектурного решения

```text
Проблема:
Вариант A (самое простое решение):
Вариант B:
Критерии: качество / стоимость / сложность / безопасность / совместимость
Что известно из источников:
Что является нашей гипотезой:
Какой маленький тест проведён:
Результат и ограничения:
Выбранный вариант и причина:
При каком условии пересмотрим:
```

Пример: «Нужен ли LangGraph для пяти фиксированных шагов?» Допустим любой вывод, который подтверждён сравнением. Не выбирайте сложность ради списка технологий в резюме.

| case_id | split | expected | actual | источники допустимы? | факт верен? | запрещённое действие? | attempts | latency | usage | ошибка |
|---|---|---|---|---|---|---|---|---|---|---|
| demo-01 | dev | answered | заполнить после запуска | — | — | — | — | — | — | — |

Строка выше — шаблон, не результат. Не меняйте expected после просмотра ответа только ради совпадения. Если разметка действительно ошибочна, исправьте её с объяснением и повторите оба сравниваемых варианта.

## 5. Короткая модель угроз

| Актив | Недоверенный вход | Возможный ущерб | Контроль в коде | Негативный тест | Остаточный риск |
|---|---|---|---|---|---|
| Записи tenant | ID из запроса модели | Чужие данные в ответе | Серверная проверка доступа до контекста | Запрос чужого ID | Указать отдельно |

Сценарий — учебный пример. Наличие таблицы не доказывает реализацию контроля: приложите тест или укажите `NOT IMPLEMENTED`.

## 6. Уровни владения и review

| Уровень | Наблюдаемое поведение |
|---|---|
| L0 — познакомился | Узнаёт термин, практики нет |
| L1 — с помощью | Объясняет или выполняет с существенными подсказками |
| L2 — воспроизводит | Запускает готовый пример и описывает его |
| L3 — применяет | Самостоятельно решает похожую задачу и проверяет ошибки |
| L4 — адаптирует | Решает новое условие, объясняет компромиссы и границы |
| L5 — обучает/систематизирует | Помогает другому повторить и улучшает проверенный метод |

Это внутренняя учебная рубрика, не официальная сертификация. Уровень ставится **по отдельному навыку**, не по всему курсу сразу. Самооценка и проверка другим человеком отмечаются отдельно. Минимальный технический разговор полезен уже с честным L2/L3 по отдельным темам; решение о сотрудничестве не определяется автоматической суммой баллов.
