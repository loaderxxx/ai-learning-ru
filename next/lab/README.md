# «Сверка» — локальный учебный инструмент

Нужны компьютер и Python 3.11+. Стандартная библиотека, установка пакетов для приложения не требуется. Скачайте весь репозиторий через GitHub **Code → Download ZIP**, распакуйте и откройте терминал в папке, содержащей главную README. Либо используйте свой Git-клон.

```bash
python next/lab/server.py
```

Откройте `http://127.0.0.1:8765` на том же компьютере. Нажмите **Учебный пример → Собрать карточку**, сравните цитаты, отметьте самопроверку и скачайте JSON. Остановка — Ctrl+C. В вашей системе команда может называться `python3` или `py`.

## Режимы

**Демо:** заранее подготовленный ответ только на fixture note.txt. Модель не вызывается; для другого текста возвращается понятная ошибка. Это проверяемый старт интерфейса.

**Ollama:** сначала пройдите [локальный запуск](../03-local/02-connect.md), установите модель и отключите облачные возможности Ollama. Пример команды с вашей моделью:

```bash
python next/lab/server.py --model ИМЯ_ИЗ_OLLAMA_LIST --timeout 60
```

Замените `ИМЯ_ИЗ_OLLAMA_LIST` точным именем своей установленной модели. Выберите соответствующий режим в форме. Приложение обращается только к `http://127.0.0.1:11434/api/chat`, не использует системный HTTP-прокси и не следует перенаправлениям. Сам по себе loopback-адрес не доказывает, что Ollama не передаёт инференс в облако: важна конфигурация движка.

## Договор результата

Ровно шесть полей, у каждого `value` и `quote`. Неизвестное: оба null. Известное: строковое значение и точная непустая цитата, присутствующая в переданном тексте. Предел ввода — 8000 символов; запроса — 32 KiB; ответа backend — 64 KiB. Это пределы приложения, не гарантия, что любой контекст поместится в выбранную модель.

Проверка структуры не понимает смысл. Неправильная цена рядом с настоящей цитатой может пройти её; этому посвящён отдельный тест. Окончательный просмотр остаётся у человека.

При изменении текста или режима старый результат и отметка проверки сбрасываются. Ответ на старую редакцию, пришедший позже, отбрасывается. Экспорт включает исходный текст, SHA-256, режим, модель, длительность ответа и самоотметку проверки. Не публикуйте экспорт личной заметки без просмотра.

Приложение не записывает заметки на диск, не ведёт журнал их содержимого и не отправляет сообщения. Браузер, ОС и Ollama имеют собственное поведение хранения; весь компьютер этим утверждением не охвачен.

## Проверки

```bash
python -m unittest discover -s next/lab -p 'test_*.py' -v
python next/lab/compare_runs.py next/fixtures/comparison-example.json
```

Дополнительная проверка JS требует Node 18+ и работающего локального сервера на 8765:

```bash
node next/lab/test_ui_state.js
```

Она использует минимальную замену DOM и реальный локальный HTTP, проверяет состояния и экспорт, **не визуальную работу браузера**. Адаптер в Python-тестах получает mock-ответы, не настоящий ответ LLM. [Фактические результаты](../VALIDATION.md).

## Границы первой версии

Только текст, не ASR/OCR; один обрабатываемый запрос; локальный доступ; нет аккаунтов, синхронизации и общей базы. Python http.server не рекомендуется для production (P04). Для публичного сервиса нужны другое размещение, доступ пользователей, лимиты, хранение и проверка ошибок. Не открывайте этот демонстрационный сервер в интернет как готовый продукт.
