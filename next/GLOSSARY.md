# Словарь без лишних терминов

| Термин | Что означает в этой программе |
|---|---|
| Диктовка | Превращение речи в редактируемый текст |
| Voice-разговор | Диалог с голосовым ответом; не гарантированная дословная стенограмма |
| Мультимодальность | Работа с разными типами входа: текстом, изображением, звуком |
| OCR / ASR | Распознавание текста изображения / речи |
| Инференс | Получение ответа уже обученной модели |
| Локальная модель | Веса и вычисление находятся на выбранном устройстве; это нужно проверить для конкретного режима |
| Квантизация | Более компактное представление весов с возможным изменением качества |
| Контекст | Данные, доступные модели в конкретном запросе |
| JSON schema | Описание допустимой структуры ответа; не доказательство его истинности |
| Mock | Управляемая замена внешнего сервиса для проверки кода |
| Handoff | Передача задачи с состоянием и достаточными исходниками |
| Workflow | Заранее заданные шаги; модель может участвовать в отдельных шагах |
| Агент | Система, в которой модель выбирает дальнейшие шаги и использование инструментов |
| Baseline | Исходный простой способ, с которым сравнивают изменение |
| Пилот | Ограниченная проверка с реальными добровольными пользователями |
