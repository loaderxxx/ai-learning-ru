## Что проверяют тесты

Python: обязательные шесть полей, точные цитаты, неизвестные значения, пределы входа и ответа; ошибки и схема mock-ответов Ollama; маршруты, ограничения Host/Origin и запроса локального сервера; парность случаев, неизвестные токены и ошибочные записи сравнения.

Отдельный тест показывает ограничение: неверное значение с настоящей цитатой может пройти структурную проверку. Проверка смысла остаётся у человека.

JS: шесть полей и три неизвестных в демо; запрет экспорта до самопроверки; содержимое экспорта; сброс результата при редактировании; ошибка другого текста в демо; отбрасывание устаревшего ответа; понятная ошибка ненастроенной модели. Эти проверки объединены в шесть исполняемых сценариев.

## Что не запускалось

- Реальная LLM/Ollama и измерение её качества, скорости, памяти или работы без сети.
- Распознавание собственной записи, обработка картинки моделью и видео в пользовательском аккаунте.
- Автономная система из нескольких агентов: опубликовано упражнение с ручной передачей ролям.
- Пилот с участниками, наблюдение их результатов и измерение экономии времени.
- Полный браузерный прогон приложения. Браузер отсутствовал; попытка загрузки завершилась ошибкой архива. Проверка JS с заменой DOM не заменяет проверку отображения, доступности и скачивания в браузере.

Оценки длительности занятий предварительные. Пример сравнения стратегий помечен `illustrative_synthetic`; его результаты нельзя использовать как измеренный benchmark.

## Как воспроизвести доступные проверки

Из корня репозитория:

```bash
python -m unittest discover -s next/lab -p 'test_*.py' -v
python next/lab/compare_runs.py next/fixtures/comparison-example.json
```

Для проверки состояний JS запустите приложение на порту 8765, затем в другом терминале `node next/lab/test_ui_state.js` (Node 18+). Для реального пользовательского прохода откройте браузер и выполните [занятие о запуске](02-product/02-build.md).
