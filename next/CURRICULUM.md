# Как проходить четыре блока

Не нужно сначала освоить все прошлые технические главы. Первый блок доступен после [первого разговора](../START_HERE.md). Для запуска приложения понадобятся компьютер, Python 3.11+ и умение открыть терминал. Для локального инференса — выбранный движок и модель, подходящие устройству.

| Блок | Занятия | Оценка до пилота | Контрольная точка |
|---|---|---|---|
| Голос и изображения | 4 | 3–4 ч | Исправления и неизвестное сохранены, источник каждого факта указан |
| Свой инструмент | 4 | 5–8 ч | Приложение запускается; другой человек понимает первый шаг |
| Локальная модель | 4 | 6–10 ч | Модель реально отвечает, место выполнения проверено, ограничения записаны |
| Несколько ролей | 4 | 4–7 ч | Одинаковые задачи проверены по одному критерию, затраты учтены |

Сумма диапазонов — 18–29 часов. Пилот с другими людьми и установка могут потребовать больше времени; календарь не назначен.

## Четыре разных статуса

**Разобрался:** объясняете, где возникает ошибка. **Воспроизвёл:** есть фактический запуск или собственная запись с проверкой. **Применил:** новое условие обработано без готового ответа. **Передал:** другой человек повторил нужную проверку. Эти статусы относятся к конкретному навыку, а не ко всему курсу сразу.

Приложение без модели подтверждает работу интерфейса и договора данных. Mock-ответ подтверждает обработку ответа API. Только настоящий вызов установленной модели подтверждает локальную интеграцию. Сам по себе ни один из них не доказывает качество ответов на новых задачах.

## Одна работа вместо папки бюрократии

Для каждого блока сохраните [короткий результат](templates/RESULT.md): исходник, версия, проверка, новое условие и ограничение. Для сравнения моделей/ролей добавьте [план эксперимента](templates/EXPERIMENT.md). Публиковать свою запись или заметку необязательно.

На первых шагах используйте синтетические материалы из курса. Если добровольно приглашаете проверяющего, покажите учебную задачу и попросите описать затруднение. Набор участников авторами ещё не проведён.
