# Блок 2. Свой небольшой AI-инструмент

Соберём «Сверку»: проверенный текст заметки → шесть полей с цитатами → просмотр человеком → скачивание результата. Начальная версия уже находится в репозитории. Она работает в деморежиме без ключа и модели.

| Занятие | Действие | Проверяемый результат |
|---|---|---|
| [1. Нужда человека](01-need.md) | Определить одну работу и границы | Короткое описание продукта |
| [2. Запуск приложения](02-build.md) | Запустить локально, проверить состояния | Собственная карточка и экспорт |
| [3. Маленький пилот](03-pilot.md) | Наблюдать добровольное прохождение | Запись затруднений, а не мнение автора |
| [4. Изменение и выпуск](04-release.md) | Исправить одно наблюдаемое затруднение | Воспроизводимая версия с ограничениями |

Ориентир — 5–8 часов, ожидание добровольцев отдельно. На компьютере нужны Python 3.11+ и терминал. На телефоне можно спроектировать бумажную форму и проверить её понятность; запуск кода останется отдельным шагом.

Статус: учебный локальный прототип. Исходный код опубликован, но сервис для внешних пользователей не развёрнут. Реальный пилот и интеграцию с вашей моделью вы проводите в заданиях.
