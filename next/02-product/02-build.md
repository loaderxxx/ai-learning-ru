# 2. Запускаем «Сверку» и проверяем поведение

**Цель:** получить собственный локальный запуск, а не только прочитать код. Ориентир — 60–90 минут. Для телефона используйте бумажный прототип предыдущего занятия и отметьте запуск как невыполненный.

## Запуск

Скачайте весь репозиторий: **Code → Download ZIP**, распакуйте. Откройте терминал в папке с главной README. Проверьте версию Python и запустите сервер:

```bash
python --version
python next/lab/server.py
```

Нужен Python 3.11+. Если команда в вашей системе называется `python3` или `py`, замените её в обоих местах. Откройте `http://127.0.0.1:8765` на этом же компьютере. Подробности и варианты ошибок — в [README приложения](../lab/README.md).

## Шесть наблюдений

1. Нажмите **Учебный пример**, затем **Собрать карточку**. Появляются шесть полей, три из них неизвестны.
2. Найдите цитату об исправленной цене. Сравните 1500 в результате с 1500 в исходном тексте.
3. Проверьте, что экспорт недоступен до отметки самопроверки. Поставьте отметку и скачайте JSON.
4. Откройте JSON обычным текстовым редактором. В нём есть исходный текст: это важно при последующей передаче файла.
5. Измените заметку. Старая карточка и отметка должны сброситься. Повторный запрос в деморежиме отклоняется: готовый разбор относится только к исходному учебному примеру.
6. Выберите Ollama без настройки модели. Прочитайте ошибку. Реальная модель подключается в следующем блоке; демо не имитирует универсальный ИИ.

Остановите сервер через Ctrl+C. При повторном запуске приложение не должно восстановить прошлую заметку из своей базы: такой базы здесь нет.

## Если вы программируете

Прочитайте `core.py`, затем `server.py`, `ollama_client.py` и `app.js` в [папке приложения](../lab/). Найдите три разные проверки: структура JSON, присутствие цитаты в источнике и человеческая оценка смысла. Первые две автоматизированы; третья остаётся необходимой.

Запустите Python-тесты по инструкции приложения. Объясните случай, когда значение «9000» с настоящей цитатой о 1500 проходит структурную проверку. Этот тест показывает ограничение валидатора, а не правильность такого результата.

Сохраните версию Python, команды, результат и один сбой в [шаблоне](../templates/RESULT.md). Если интерфейс у вас не отрисовался, так и запишите: автоматические проверки курса не заменяют ваш браузерный запуск.
