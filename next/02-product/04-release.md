# 4. Делаем одно изменение и описываем выпуск

**Цель:** завершить небольшой цикл продукта: наблюдение → изменение → повторная проверка. Ориентир — 90–120 минут. Общедоступное размещение сервера в задание не входит.

Выберите затруднение из пилота. Если пилота ещё не было, используйте учебную гипотезу: «Человек не понимает, что JSON содержит исходную заметку». Не приписывайте эту гипотезу реальному пользователю.

## Небольшая правка

Без кода: исправьте бумажный прототип и повторите прохождение с добровольцем. С кодом: измените одну подпись или пояснение в `index.html`, либо способ показа цитаты в `app.js`/`style.css`. Сохраните прежнюю версию или отдельный Git-коммит, чтобы сравнить результат.

```text
Помоги изменить одну часть учебного интерфейса.
Проблема: [наблюдение]. Ожидаемое поведение: [проверяемый критерий].
Предложи минимальную правку в указанных файлах.
Сохрани сброс проверки при изменении исходника и явные неизвестные поля.
Объясни, как вручную проверить результат. Не добавляй внешних запросов.
```

Посмотрите предложенное изменение сами. Запустите приложение и повторите путь: пример → карточка → проверка → экспорт → редактирование исходника. После редактирования нельзя скачать старый результат как проверенный. Смысловые и сетевые изменения дополнительно требуют подходящих тестов, а исправление опечатки — обычного просмотра.

## Запись о версии

Укажите проблему, изменение, проведённую проверку и оставшееся ограничение. Отдельно перечислите, что запускалось: демо, Ollama, конкретная модель, браузер. Нельзя назвать модельную интеграцию подтверждённой по mock-тестам.

Для нового условия попросите другого человека найти исходный текст в экспорте. Если исправление связано с другим затруднением, выберите соответствующую проверку. Сохраните отрицательный результат тоже: это материал для следующей правки.

## Что понадобится для общего сервиса

Учебное приложение слушает только локальный адрес и использует стандартный Python-сервер. Официальная документация не рекомендует `http.server` для production (P04). Переход к сервису для чужих данных — отдельная разработка: развёртывание, авторизация, лимиты, доступ к модели, хранение и удаление данных, журнал ошибок и восстановление.

В текущем блоке готовым результатом считается воспроизводимый **локальный** инструмент с понятным описанием. Собственный проект можно развивать дальше, сохраняя честную границу проверенного.
