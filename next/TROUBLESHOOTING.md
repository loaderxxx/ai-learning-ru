# Если что-то не получается

| Симптом | Что проверить |
|---|---|
| В телефоне нет нужной кнопки Voice/видео | Посмотрите справку своего режима; используйте доступную диктовку или собственный аудиофайл. Не отмечайте отсутствующую функцию выполненной |
| Слова распознаны, число потерялось | Прослушайте отрезок с числом, сохраните исправление и исходную формулировку |
| Картинка загружается, мелкий текст не читается | Возьмите PNG полного размера; не отрезайте единицы и пометку версии |
| Команда python не найдена | Проверьте установку Python; в вашей системе команда может называться python3 или py |
| Порт 8765 занят | Запустите `python next/lab/server.py --port 8766` и откройте новый адрес |
| Телефон не открывает 127.0.0.1 компьютера | Это адрес самого устройства. Открывайте демо в браузере того компьютера, где запущен сервер |
| Изменённый текст не работает в демо | Это ожидаемо: демо показывает только заданный пример. Для своего текста нужен режим Ollama |
| Ollama недоступен | Проверьте, запущен ли он на том же компьютере, модель установлена и указан `--model` |
| Ответ долго не приходит | Проверьте нагрузку и размер модели; при необходимости измените `--timeout`. Не запускайте бесконечные повторы |
| Модель вернула не ту структуру | Проверьте поддержку structured outputs и ошибку сервера; не убирайте проверки только ради зелёного результата |
| Цитата есть, но значение неправильное | Сверьте смысл; совпадение строки и истинность вывода — разные проверки |
| Экспорт стал недоступен после редактирования | Так и задумано: новый исходник требует нового результата и повторной проверки |
| Несколько ролей медленнее одного чата | Учтите передачу, ожидание и исправления. Это допустимый результат эксперимента |

Для вопроса достаточно команды, режима, обезличенного сообщения ошибки и ожидаемого результата. Не прикладывайте ключи и личные записи. [К программе](README.md).
