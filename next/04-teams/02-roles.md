# 2. Разделяем работу на три ограниченные роли

**Цель:** проверить, помогает ли отдельная проверка исходника. Ориентир — 60–90 минут. Используйте те же случаи, источник и модель, что в простом способе. Если модель изменилась, отметьте дополнительное различие.

## Договор ролей

| Роль | Получает | Возвращает | Граница |
|---|---|---|---|
| Извлекатель | Исходный текст и шесть полей | Значения, цитаты, null | Не дополняет сведения извне |
| Проверяющий | Исходник, критерий и черновик | Ошибки по полям с основанием | Не одобряет только из-за уверенного тона |
| Сборщик | Исходник, черновик и проверку | Итоговую карточку | Не скрывает неразрешённый конфликт |

Откройте отдельный разговор для каждой роли. Переносите данные вручную. Проверяющему обязательно нужен исходник: один пересказ извлекателя может уже содержать ошибку. Разные разговоры уменьшают влияние общей истории, но не делают ошибки одной модели статистически независимыми.

## Готовые задания

Извлекатель использует запрос из [прошлого занятия](01-baseline.md). Проверяющему отправьте:

```text
Проверь черновик по исходнику. Для каждого нарушения укажи:
поле, неверное утверждение, точный фрагмент источника, нужное исправление.
Проверь пропущенные оговорки, неподтверждённые даты и отменённые значения.
Если нарушения нет, напиши «не найдено», без гарантии безошибочности.
Не добавляй факты из памяти. Источник: [...]. Черновик: [...].
```

Сборщику:

```text
Собери итоговые шесть полей из источника с учётом проверки.
Исправляй только то, что подтверждено источником. Если проверяющий
ошибся, укажи расхождение отдельно. Неизвестное оставь null.
Верни карточку и перечень внесённых изменений. Затем остановись.
Источник: [...]. Черновик: [...]. Проверка: [...].
```

Ограничьте эксперимент одной цепочкой из трёх вызовов на случай. Любые дополнительные уточнения записывайте как повторные попытки с затратами. Не запускайте бесконечную взаимную перепроверку.

## Проверка человеком

Примите или отклоните итог по тому же правилу, что одиночный ответ. Дополнительные вызовы входят в цену подхода. Исследование A02 описывает промышленный опыт другой задачи; оно не доказывает пользу трёх ролей для нашей карточки.

Для нового условия дайте проверяющему черновик с ценой 9000 и настоящей цитатой о 1500. Найдёт ли он смысловую ошибку? Сохраните фактический ответ. Наличие роли «проверяющий» само по себе не является проверкой качества.
