# Блок 4. Один исполнитель или несколько ролей

Больше вызовов модели не означает лучший результат. Здесь вы сравните один проход и разделение работы, учитывая ошибки, время человека и передачу контекста. Ориентир — 4–7 часов.

| Занятие | Практика | Итог |
|---|---|---|
| [1. Один исполнитель](01-baseline.md) | Зафиксировать простой способ | Исходный результат для сравнения |
| [2. Три ограниченные роли](02-roles.md) | Извлечение, проверка, сборка | Проверяемая цепочка без лишних действий |
| [3. Передача задачи](03-handoff.md) | Сохранить нужное состояние | Пакет, понятный без полного чата |
| [4. Сравнение способов](04-compare.md) | Посчитать качество и все затраты | Решение, нужна ли сложность |

Достаточно доступного чата или локальной модели и текстовых заметок. Роли можно разыграть вручную в отдельных разговорах. Это **учебная имитация разделения работы**, а не готовый автономный многоагентный сервис. Курс не запускает исполнителей и не отправляет им ваши данные автоматически.

Заранее заданная последовательность шагов — workflow. Система, сама выбирающая дальнейшие шаги и инструменты в рамках цели, ближе к агенту. Это полезное различие из A01; конкретные реализации могут сочетать оба подхода. В первом эксперименте используем фиксированные роли и ручную передачу.
