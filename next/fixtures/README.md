# Учебные данные и контрольные ответы

Все материалы оригинальные и вымышленные. [note.txt](note.txt) — сценарий собственной записи, не результат реального ASR. Запишите его своим голосом, если хотите проверить распознавание. Готового аудиофайла в выпуске нет.

- [Архивная карточка PNG](board-v1.png) — вход для распознавания изображения; [исходный SVG](board-v1.svg) нужен для воспроизводимости.
- [Текст обновления](note.txt) — версия 2 с оговорками и исправлениями.
- [Готовая карточка демо](demo-card.json) — ответ только для этого текста. Не передавайте её модели во время проверки.
- [Восемь случаев](review-cases.json) — поля input и review_expectation. Модели показывайте только input.
- [Пример записей сравнения](comparison-example.json) — вымышленные числа для проверки формата, не измерение моделей.

## Контроль первого блока

Из изображения версии 1: 11:30, Москва; 1200 RUB; 18 участников; дата отсутствует; точного URL нет. Из обновления: 12:15 по московскому времени; 1500 RUB; дата и число участников новой встречи неизвестны; ссылки нет. Тимур готовит три слайда к пятнице, точная дата пятницы не названа.

Приоритет обновления указан прямо в тексте: старая карточка устарела. Число 18 нельзя перенести в новый результат, поскольку новая версия явно говорит об отсутствии актуального количества. Срок «к пятнице» не превращается в конкретную дату автоматически.

Извлечь старую карточку правильно и определить актуальные условия — разные задачи. Ошибки отмечайте отдельно.
