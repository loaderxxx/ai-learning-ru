# Блок 3. Локальная модель: проверяем на своём устройстве

Здесь вы подключите настоящую модель к «Сверке», проверите границу локального выполнения и оцените результат на новых заметках. Ориентир — 6–10 часов; скачивание весов и устранение несовместимости могут занять больше.

| Занятие | Что проверяем | Итог |
|---|---|---|
| [1. Устройство и модель](01-device.md) | Совместимость и доступные ресурсы | Обоснованный выбор либо решение отложить запуск |
| [2. Подключение](02-connect.md) | Реальный ответ через локальный API | Своя карточка с именем модели |
| [3. Работа без облака](03-offline.md) | Поведение после отключения сети | Запись условий и наблюдений |
| [4. Оценка качества](04-evaluate.md) | Смысл, ошибки, время исправления | Маленький воспроизводимый отчёт |

Основной код использует **Ollama**. **LM Studio** упоминается как отдельный графический вариант для изучения локального запуска; адаптера к нему в приложении нет. Универсальной модели, подходящей любому компьютеру, не назначаем.

Если компьютер не подходит, не нужно покупать новый ради курса. Заполните выбор и ограничения, продолжите в деморежиме. Отметьте локальный запуск как невыполненный; соседние блоки от этого не закрываются.
