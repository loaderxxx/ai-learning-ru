# 2. Подключаем Ollama к приложению

**Цель:** получить реальный ответ установленной модели. Ориентир — 1,5–3 часа; зависит от устройства и загрузки. В проверках авторов использовались mock-ответы, поэтому ваш фактический запуск — отдельный результат.

## Подготовьте движок

Установите Ollama по [официальному quickstart](https://docs.ollama.com/quickstart) для своей ОС. Просмотрите инструкцию установки перед выполнением команд. Загрузите выбранную в прошлом занятии **локальную** модель по её карточке. Не подменяйте её вариантом с облачным выполнением.

По [официальному FAQ](https://docs.ollama.com/faq) отключите облачные возможности: `OLLAMA_NO_CLOUD=1` в окружении процесса **Ollama** или настройка `disable_ollama_cloud` в `server.json` согласно инструкции для вашей установки. Полностью перезапустите движок. В журнале запуска найдите `Ollama cloud disabled: true`. Установка переменной только для Python-приложения не меняет уже запущенный Ollama.

Убедитесь, что API доступен на стандартном локальном адресе `127.0.0.1:11434`. Не меняйте его на внешний интерфейс для этого задания.

## Проверьте модель и приложение

```bash
ollama list
ollama show ИМЯ_МОДЕЛИ
ollama run ИМЯ_МОДЕЛИ
```

В командах вместо `ИМЯ_МОДЕЛИ` используйте точное имя из своего каталога и `ollama list`; это заполнитель, не имя готовой модели. Задайте короткий вопрос по вымышленной заметке и дождитесь ответа. Затем из корня репозитория запустите:

```bash
python next/lab/server.py --model ИМЯ_МОДЕЛИ --timeout 60
```

Откройте приложение, загрузите учебный пример и переключите режим на Ollama. Соберите карточку, проверьте все шесть полей и цитаты. Затем измените цену в заметке на 1700 и повторите: отличие от демо должно подтверждаться новым корректным ответом, а не просто доступностью кнопки.

## Что делает адаптер

Он вызывает `/api/chat`, передаёт JSON-схему, запрашивает `stream: false` и проверяет полученный ответ. Структурированный вывод помогает получить нужную форму, но не гарантирует смысл. Не каждая модель одинаково хорошо выполняет такое задание; официальные сведения — L02–L03 в [каталоге](../SOURCES.md).

Если ответ не проходит схему или цитата отсутствует в тексте, приложение возвращает ошибку. Не отключайте проверку ради зелёного экрана. Сохраните модель, вход и вид ошибки; сначала попробуйте короткий исходник. При медленном ответе допустимо увеличить `--timeout` до 300, отдельно учитывая время ожидания. Не запускайте одновременно несколько попыток.

Сохраните экспорт после ручной проверки и отметьте, что это **настоящий** модельный вызов. Для GUI-эксперимента с LM Studio используйте отдельный чат: текущий адаптер с ним не совместим напрямую.
