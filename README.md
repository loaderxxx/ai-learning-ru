# ИИ с нуля — учимся вместе
**Cursor · ChatGPT · Claude | Практика на русском языке**

Разбираем официальные учебные материалы и пробуем инструменты на небольших понятных задачах. Здесь можно пройти путь вместе с авторами: прочитать короткое объяснение, выполнить задание и сравнить результат с исходными данными.

**Открытый старт · версия 0.1.1, 23 сентября 2026.** Опубликован первый набор из семи занятий. Проверка упражнений группой участников ещё впереди. Это независимая учебная инициатива, не официальный курс и не партнёрская программа производителей.

## Начать

1. Откройте [СТАРТ](START_HERE.md).
2. Пройдите [маршрут из семи занятий](ROADMAP.md) в удобном темпе.
3. Скопируйте [дневник участника](templates/progress.md) в свои заметки.
4. Смотрите [изменения программы](CHANGELOG.md) и предлагайте исправления по [правилам участия](CONTRIBUTING.md).

Понимать программирование и пользоваться терминалом для этого старта не требуется. Для Cursor нужен компьютер; текстовые задания можно начать в доступном вам чате. На занятие ориентировочно 20–40 минут — это наша оценка, а не длительность полного официального курса.

## Что получится

- понятный запрос к ИИ и исправленная версия ответа;
- небольшой текстовый файл, отредактированный с Cursor;
- сравнение двух ответов с проверкой фактов;
- своя короткая памятка для повторения задачи.

## Формат первого этапа
Короткие занятия и работа с текстом. API, MCP, серверы, сложные агенты и программирование больших приложений в этот этап не входят. Читать материалы можно без подписки на нашу программу; доступ и лимиты самих сервисов определяют их провайдеры. Покупать все инструменты ради старта не нужно.

Ведущие будут добавлять разборы по мере фактического прохождения. В журнале отдельно отмечаются подготовка материала и его проверка на практике. Публичных результатов участников пока нет; срок следующего выпуска не назначен.
