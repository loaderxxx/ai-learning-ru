## Как будем двигаться

1. Выберите один шаг по ссылке выше.
2. Прочитайте объяснение и выполните маленькое задание.
3. Сверьте результат с условиями проверки в занятии.
4. Перейдите по ссылке следующего занятия внизу страницы.

Для начала достаточно одного доступного чата. Cursor нужен только для занятий с файлами и требует компьютера. Покупать все инструменты ради старта не нужно; доступ и лимиты сервисов определяют их провайдеры.

## Что есть сейчас и как растёт проект

Опубликованы первый разговор для новичка и семь коротких занятий: основы, ChatGPT, Claude, Cursor, сравнение ответов и итоговая практика. На занятие ориентировочно 20–40 минут — это наша оценка, проходите в удобном темпе.

Мы будем проходить материалы вместе с вами, собирать непонятные места, дополнять объяснения и добавлять следующие шаги. Изменения появятся в [журнале программы](CHANGELOG.md). Если вы застряли, напишите, на каком шаге: [как задать вопрос или предложить исправление](CONTRIBUTING.md).

**Версия 0.2 · 23 сентября 2026.** Материалы подготовлены к первому прохождению; результаты обучения участников пока не подтверждены. Расписание живых занятий не установлено.
