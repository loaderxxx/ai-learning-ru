## Как двигаться в начальном маршруте

1. Выберите один шаг по ссылке выше.
2. Прочитайте объяснение и выполните маленькое задание.
3. Сверьте результат с условиями проверки в занятии.
4. Перейдите по ссылке следующего занятия внизу страницы.

В начальном маршруте достаточно одного доступного чата. Cursor нужен для занятий с файлами и требует компьютера. Покупать все инструменты ради старта не нужно; доступ и лимиты сервисов определяют их провайдеры.

## Что есть сейчас и как растёт проект

Опубликованы два маршрута: первый разговор и семь коротких занятий для новичков; 12 модулей, лаборатория и шаблоны для разработчиков. Начальное занятие занимает ориентировочно 20–40 минут. Нагрузка технического маршрута описана в его программе; проходите в удобном темпе.

Мы будем проходить материалы вместе с вами, собирать непонятные места, дополнять объяснения и добавлять следующие шаги. Изменения появятся в [журнале программы](CHANGELOG.md). Если вы застряли, напишите, на каком шаге: [как задать вопрос или предложить исправление](CONTRIBUTING.md).

**Версия 0.3 · 23 сентября 2026.** Материалы и локальный технический стенд подготовлены. Результаты обучения участников пока не подтверждены. Расписание живых занятий не установлено.
