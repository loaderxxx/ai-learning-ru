# 2. Cursor: одна небольшая правка
**Цель:** проверить изменение текста, а не только прочитать сообщение «готово».

В [уроке Cursor о проверке](https://cursor.com/learn/reviewing-testing) разбор изменений дополняет автоматические проверки. Здесь перенесём эту базовую идею на простой текст: сравним исходный и итоговый файл вручную. Diff — представление добавленных и удалённых строк.

## Попробуйте
1. Сохраните копию meeting.md вне открытой учебной папки.
2. Попросите Cursor изменить файл:

> В meeting.md добавь раздел «Что взять» с двумя пунктами: одну книгу и блокнот. Удали только строку «Каждый приносит одну книгу», чтобы она не повторялась. Остальные сведения сохрани.

3. Посмотрите изменения в интерфейсе и откройте итоговый файл.
4. Сравните его с сохранённой копией.

## Проверьте
- Добавлены именно два пункта.
- Условие про книгу перенесено, а не потеряно.
- Остались шесть участников и 60 минут.
- Неизвестные дата, адрес и стоимость не заполнены догадками.
- Другие файлы не менялись.

Если результат неверен, попросите точечное исправление. При необходимости восстановите исходный текст из своей копии. Для этого упражнения установка пакетов, подключение сервисов и команды терминала не нужны.

**Готово:** у вас есть исходный и итоговый тексты, и вы можете своими словами перечислить изменения. Сохраните итоговую копию как личный результат упражнения.
