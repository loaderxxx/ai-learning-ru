# 1. Cursor: познакомиться с файлом
**Цель:** открыть учебную папку и получить объяснение одного файла.
**Нужно:** компьютер и доступ к Cursor. Установка и вход — по [официальному Quickstart](https://cursor.com/docs/get-started/quickstart).

Cursor позволяет обсуждать файлы и менять их с помощью ИИ. Для первого знакомства возьмём обычный текст. Это наше упрощённое упражнение; официальный учебник ориентирован прежде всего на разработку.

## Попробуйте
1. Создайте пустую учебную папку.
2. Скопируйте туда [meeting.md](../practice/meeting.md). В папке должен быть только этот учебный файл.
3. Откройте папку в Cursor и выберите файл.
4. Откройте панель Agent. При отличающемся интерфейсе сверьтесь с Quickstart.
5. Попросите:

> Прочитай meeting.md. Объясни в трёх пунктах, о чём файл. Отдельно перечисли неизвестные сведения. Файл пока не изменяй.

Если файл не попал в контекст, добавьте его через доступный в вашей версии выбор файлов. Попросите назвать прочитанный файл. Сравните ответ с его текстом сами.

## Проверьте
- Ответ относится к meeting.md.
- В нём нет придуманного места и даты.
- Сам файл остался прежним.

**Готово:** вы видите файл и понимаете, откуда Cursor взял данные для ответа. Сохраните короткую запись в дневнике. Если Cursor пока недоступен, отметьте это, а не «выполнено».
