# 5. Сравнить два ответа
**Цель:** выбрать удобный ответ по конкретным признакам.

Это наше упражнение на вымышленных данных. Общая идея проверки результата на знакомой задаче описана в [Claude Academy](https://academy.claude.com/courses/claude-101/getting-better-results). Одного примера недостаточно для рейтинга моделей.

## Попробуйте
В двух доступных чатах отправьте одинаковый исходный [текст встречи](../practice/meeting.md) и одинаковый запрос из [занятия 3](03-chatgpt.md). Начинайте новые разговоры, чтобы прежние уточнения не влияли на результат.

Если доступен один сервис, получите две версии в двух новых чатах. Назовите это сравнением вариантов одного сервиса.

| Признак | Ответ А | Ответ Б |
|---|---|---|
| Участники: 6; длительность: 60 минут | Да / нет | Да / нет |
| Просьба принести книгу сохранена | Да / нет | Да / нет |
| Нет выдуманных даты, адреса и цены | Да / нет | Да / нет |
| Не более 80 слов | Да / нет | Да / нет |
| Понятно, что предлагается читателю | Да / нет + почему | Да / нет + почему |

Сначала исправьте фактические ошибки. Красивый стиль сам по себе не компенсирует выдуманные сведения.

**Готово:** заполненная таблица и вывод из двух предложений: какой ответ потребовал меньше правок и чем ограничено это наблюдение. Запишите дату и видимое название модели, если оно показано; не угадывайте его.
