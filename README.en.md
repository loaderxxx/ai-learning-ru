## What you will learn

Start with programming fundamentals and a clear contract. Call a model from code, switch between eligible routes, expose constrained tools, and manage a workflow. Then build evidence-backed retrieval, understand MCP, evaluate quality, handle failures safely, enforce data boundaries, deliver a service, and measure cost and latency.

The route contains **16 complete chapters in both Russian and English**, with official reading, guided exercises, negative tests, completion criteria, and an independent variation. Select one main language and one appropriate framework; memorizing every library is not required.

## What is actually included

An original offline Python lab with two scripted model routes, tool dispatch, strict arguments, tenant-checked lookup, bounded fallback, call-ID handling, and safe events. Its **30 automated tests passed** in the release-preparation environment. It makes no network requests and is not a live LLM application.

Live provider adapters, RAG, MCP, persistent writes, and deployment are assignments you implement through the course. They are not silently claimed as ready features. [Read the verification record](ai-in-code/VALIDATION.md).

## For engineers

We are looking to connect with people who can explain the whole system, not just use a chat interface. Show your own code, how you test failures, where AI is useful, and where deterministic software is better. An equivalent existing project is welcome; completing the whole curriculum is not a mandatory application step.

**[Read the invitation and requirements](engineers/README.en.md).** Engagement terms, compensation, location, and specific roles have not been announced. Learning completion does not guarantee employment.
