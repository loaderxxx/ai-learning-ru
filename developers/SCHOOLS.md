# Какие школы и подходы мы посмотрели

Это сравнительный срез 11 школ, сетей и учебных инициатив по открытым страницам на 23.09.2026. Полные закрытые программы и обучение внутри кампусов мы не проверяли. Наличие темы в каталоге не доказывает её освоение каждым учащимся; отсутствие упоминания не доказывает отсутствие темы.

| Школа или инициатива | Что заявлено в открытом источнике | Как это связано с нашим маршрутом |
|---|---|---|
| [School 21](https://21-school.ru/training-and-platform) | Проектное обучение, взаимные и автоматические проверки | Сохраняем практику и объяснение решения другому участнику |
| [École 42](https://42.fr/en/the-program/software-engineer-degree/) | Общее ядро и специализации, в том числе ИИ | Делаем дополнительный проект для уже умеющего программировать |
| [Codam](https://www.codam.nl/en/faq/) | Основы, затем AI/ML и LLM-приложения | Начинаем с диагностики, не предполагаем нулевой опыт в ИИ |
| [Hive Helsinki](https://www.hive.fi/studies/curriculum/) | Основы на Go, full stack и углубление | Разрешаем перенос заданий на знакомый язык |
| [01Edu](https://01edu.ai/solutions/ai-native-curriculum/) | Проектный peer-to-peer маршрут с ИИ | Сам перечень AI-тем не считаем уникальным |
| [Holberton](https://hbtn.dev/programs) | В каталоге есть AI for Developers и AI/ML | Проверяем конкретные умения через задания |
| [Recurse Center](https://www.recurse.com/about) | Самостоятельный retreat для программистов | Даём опытным участникам возможность выбирать собственную задачу |
| [The Odin Project](https://www.theodinproject.com/paths) | Самостоятельные веб-маршруты | Возможный внешний источник для восстановления веб-основ |
| [Full Stack Open](https://fullstackopen.com/en/) | Открытый курс веб-разработки | Дополнительный маршрут по веб-базе |
| [Хекслет](https://ru.hexlet.io/courses) | Есть направления ИИ для разработчиков и LLM-разработки | Концентрируемся на проверяемом проектном результате |
| [Яндекс Практикум](https://practicum.yandex.ru/) | Каталог профессиональных онлайн-программ | Учитываем, что учащиеся приходят из разных форматов |

Французская школа, известная бесплатной подготовкой по принципу peer learning, — **42**. School 21 рассматриваем отдельно по её текущим источникам.

В [новости School 21 от 17.12.2025](https://21-school.ru/news/skola-cifrovyx-texnologii-skola-21-otkrylas-v-permi-ucastniki-smogut-besplatno-osvoit-vostrebovannye-it-navyki-i-novyi-modul-po-sozdaniiu-ii-agentov) уже объявлен модуль агентов на ГигаЧат. Поэтому наша формулировка — «дополнительная практика», а не «в школе этому не учат».

Если тема вам знакома, покажите результат из критериев занятия и переходите дальше. Для уточнения программы достаточно описать собственное затруднение; присылать закрытые школьные задания и чужие сообщения не требуется.
