# Уже умеете программировать? Создайте проверяемый ИИ-проект

**Практикум для разработчиков, студентов и выпускников School 21, 42 и других проектных школ.** На русском. Можно проходить самостоятельно или обсуждать решения с напарником.

Вы умеете писать функции и запускать программу. Теперь попробуем два следующих навыка: использовать ИИ при разработке и создавать приложения, в которых работает языковая модель. Будем проверять оба результата: код и поведение приложения.

**→ [Начать: диагностика и первый запуск](modules/00-entry.md)**

## Что вы соберёте

Помощника по базе знаний вымышленного клуба разработчиков. Он находит сведения, показывает источник, отказывается отвечать без основания и использует только разрешённые операции. У вас останутся код, набор проверок, результаты экспериментов и описание ограничений.

Начальный [учебный стенд](labs/knowledge-assistant/README.md) работает локально без сторонних Python-пакетов, API-ключей и сетевых запросов. Он ищет и извлекает текст по простым правилам. Модель, MCP и A2A подключаются в заданиях отдельно: наличие стенда не означает, что эти интеграции уже реализованы.

Для первого запуска нужен компьютер, Git и Python 3.11 или новее. Для обсуждений с моделью используйте доступный вам инструмент. Для API-заданий может потребоваться отдельный доступ и оплата провайдеру; подписка на чат и API-доступ не предполагаются взаимозаменяемыми. Можно сначала пройти локальную часть.

Если вы программируете на C, C++, Go, Java или JavaScript, используйте Python-стенд как читаемый пример или перенесите контракт на свой язык. Критерии результата остаются прежними.

## Несколько идей, которые проверим руками

- Правильный JSON ещё не означает правильный ответ.
- RAG может принести в контекст вредную инструкцию вместе с полезным текстом.
- Красиво описанный инструмент не получает от этого разрешения на действие.
- Повторный запрос после timeout может выполнить операцию дважды.
- Высокий средний балл способен скрывать опасную ошибку в редком сценарии.
- Несколько агентов полезны только тогда, когда решают конкретную проблему лучше более простой схемы.

## Почему это дополнение к школе

School 21 уже объявляла модуль ИИ-агентов, а 42 и другие школы включают AI-темы. Мы не утверждаем, что этих знаний у них нет. Здесь собрана отдельная практика: пройти один проект от требований до измерения качества и проверки эксплуатации. Вы сами определяете, что для вас новое.

[Краткая карта школ](SCHOOLS.md) · [Официальные источники](SOURCES.md) · [Весь план и критерии](CURRICULUM.md)

Проекты школы выполняйте по её правилам. Наши синтетические задания не являются решениями школьных экзаменов, зачётами или официальной сертификацией. Программа независима от Сбера, School 21, 42 и производителей инструментов.

## Как учиться вместе

У каждого модуля есть задача, проверка результата и вопрос для объяснения. Сначала попробуйте сами, затем сравните решение с напарником по [правилам взаимной проверки](PEER_REVIEW.md). Если напарника нет, выполните самопроверку; внешний review остаётся непройденным.
