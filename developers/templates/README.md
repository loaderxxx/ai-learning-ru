# Шаблоны участника

Скопируйте нужный шаблон в свой учебный проект и заполните фактическими данными. Пустое поле лучше выдуманного результата.

- [Спецификация](SPEC.md) — задача, условия, границы и критерии.
- [Эксперимент](EXPERIMENT.md) — сравнение baseline и изменения.
- [Паспорт интеграции](INTEGRATION.md) — версии и фактическая совместимость.
- [Взаимная проверка](REVIEW.md) — что проверил другой человек.
- [Модель угроз](THREAT_MODEL.md) — активы, входы, ограничения и проверки.
- [Пример Python CI](python-ci.yml) — шаблон; сам по себе не запускается.

Не публикуйте ключи, реальные закрытые документы и чужую переписку. Личные заметки и результаты можно оставить у себя.
