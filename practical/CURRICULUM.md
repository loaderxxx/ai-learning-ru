# План прикладного практикума

Вход: вы умеете отправить запрос и прочитать ответ критически. Если это пока незнакомо, пройдите [первый разговор](../START_HERE.md). Основной путь не требует программирования. Для расширений нужны Python 3.11+ и работа с файлами.

## Последовательность

| Этап | Миссии | Проверка перехода |
|---|---|---|
| Получить правильные исходные данные | 1–2 | У каждого существенного утверждения есть источник или расчёт |
| Разобраться и сохранить знания | 3–4 | Можно объяснить выбор и найти ответ после обновления документа |
| Повторить задачу и передать результат | 5–6 | Предложение действия отделено от его исполнения, кейс воспроизводим |

Миссию 2 можно проходить независимо. Для 4 и 5 сначала прочитайте оба документа из миссии 1. В основном пути достаточно ручной симуляции автоматизации; работающий n8n или код — отдельный уровень с фактическим запуском.

## Два режима на одних данных

**Без кода:** чат помогает извлечь и оформить данные, вы проверяете источники и числа вручную. Сохраните исходный ответ, одну исправленную ошибку и финальный результат. Автоматизацию сначала воспроизведите как последовательность карточек на бумаге или в заметках.

**С кодом:** повторите тот же результат программой, добавьте неизвестный заранее случай и объясните границы. Нельзя считать модельное извлечение проверенным только потому, что детерминированный расчёт прошёл тесты. Для миссии 5 нужны отдельные проверки повторов и действий во внешней системе, если вы её подключили.

## Что считать завершением

| Статус | Доказательство |
|---|---|
| Разобрался | Объясняете одну типичную ошибку и как её заметить |
| Выполнил на примере | Есть результат, исходные файлы и проверка |
| Перенёс навык | Новое условие обработано без готового ответа |
| Проверен другим | Другой человек повторил ключевую проверку |

Не нужно заполнять десятки документов. Один [RESULT.md](templates/RESULT.md) на миссию достаточен. Имена участников, личная переписка и конфиденциальные файлы для сдачи не требуются.

## Маршрут за один вечер

Миссия 1 → ручной расчёт миссии 2 → короткий кейс по миссии 6. Затем выберите базу знаний или автоматизацию по своей задаче. Изучать каждый доступный сервис не обязательно.
