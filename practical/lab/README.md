# Локальная проверка учебного отчёта

Python 3.11+, стандартная библиотека. Не нужны ключи, сеть и установленные пакеты. Скрипт не вызывает ИИ и не меняет исходные данные; выводит JSON в терминал. Это проверка конкретного показателя, не готовый сервис обработки произвольных документов.

## Запуск из корня репозитория

```bash
python practical/lab/audit_orders.py practical/fixtures/orders.json
python -m unittest discover -s practical/lab -p 'test_*.py' -v
```

На компьютере команда Python может называться `python3` или `py`; выберите установленную версию. Если нет Python, выполните [ручную миссию](../missions/02-data.md).

Ожидание: суммы 3500.00 RUB и 25.00 USD; включены r01, r02, r06, r08; каждая другая строка имеет причину исключения. Сохранённый результат: [expected-report.json](expected-report.json).

## Договор входа

Вход — JSON-массив до 10000 строк. Каждая строка содержит ровно `row`, `order_id`, `status`, `amount`, `currency`. Идентификаторы: 1–30 латинских букв, цифр, `_` или `-`; `row` уникален во всём входе. Статусы: paid, refunded, cancelled. Валюты: RUB, USD. Другие значения отклоняются, а не угадываются.

Сумма — `null` или неотрицательная десятичная строка: до 12 цифр в целой части и до двух после точки/запятой. Допустимы корректные группы тысяч через пробел, включая неразрывный. Нулевое значение допустимо. Отрицательные суммы, экспоненциальная запись, NaN, float и bool отклоняются. Эти ограничения относятся к учебному контракту.

Группировка идёт по `order_id`. Сравниваются нормализованные сумма, валюта и статус. Если есть разные значения, вся группа исключается как конфликт. У точных повторов учитывается первая строка; затем исключаются не-paid и неизвестные суммы. Итог называется суммой известных оплаченных заказов без конфликтов. Не выполняется пересчёт валют или восстановление истории возвратов.

## Коды завершения

0 — валидный вход разобран; в отчёте всё ещё могут быть исключённые строки. 2 — ошибка формата, чтения файла или аргументов. Код 0 не означает отсутствие проблем в данных. В stdout при ошибке входа отчёт не выдаётся.

## Как усложнить

Сначала придумайте новый случай и ожидаемое решение, затем меняйте код. Добавление третьей валюты требует изменения учебного договора. Реальный конвейер также потребует ограничений размера файла до чтения, сохранения происхождения и отдельного управления обновлениями. Этот пример не принимает HTTP-запросы и не предоставляет многопользовательский сервис.

14 тестов проверяют расчёт и происхождение строк, дубли, конфликты, валюты, пропуски, форматы, схему, ограничения и неизменность входа. Они не доказывают корректность извлечения исходной таблицы моделью. [Фактическая проверка выпуска](../VALIDATION.md).
