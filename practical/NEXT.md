# Следующие четыре блока уже подготовлены

Предложения версии 0.5 развёрнуты в [единый маршрут из 16 занятий](../next/README.md). Все четыре блока доступны для чтения и самостоятельной практики; прохождение участниками ещё не подтверждено.

| Блок | Первый результат | Начать |
|---|---|---|
| Голос, изображения и видео | Проверенный текст и карточка с источниками | [Собственная короткая запись](../next/01-multimodal/01-voice.md) |
| Свой небольшой инструмент | Локальная «Сверка» с цитатами и экспортом | [Потребность и прототип](../next/02-product/01-need.md) |
| Локальные модели | Реальный запуск и проверка условий | [Устройство и модель](../next/03-local/01-device.md) |
| Один исполнитель и роли | Сопоставимые результаты и затраты | [Простой способ для сравнения](../next/04-teams/01-baseline.md) |

Порядок сохраняет один сюжет: правильно прочитать вход, сделать полезную форму, проверить модель, оценить усложнение. Каждый блок содержит задания, критерии, новое условие и переходы дальше.

Приложение в деморежиме не вызывает модель. Адаптер Ollama проверен mock-ответами; реальный инференс, распознавание, браузерный прогон и пилот участников остаются отдельными проверками. [Подробный отчёт](../next/VALIDATION.md).

Ориентир — 18–29 часов до пилота. Первый результат с голосом занимает 20–30 минут, возможен текстовый обходной путь. Подходящее оборудование нужно только для локального модельного запуска; покупать его ради курса необязательно.
