# Учебные исходники

Все документы, обращения и суммы вымышлены. Они созданы специально для практикума; не относятся к реальным участникам или мероприятиям.

| Файл | Назначение |
|---|---|
| [event-v1.md](event-v1.md) | Архивная версия объявления |
| [event-v2.md](event-v2.md) | Актуальная версия с изменениями и неизвестными полями |
| [orders.json](orders.json) | Десять строк для разбора дублей, конфликтов и единиц |
| [inbox.json](inbox.json) | Шесть записей обращений, включая повтор и неподходящую инструкцию |
| [ANSWER_KEY.md](ANSWER_KEY.md) | Разбор после самостоятельной попытки |

JSON — текстовая запись структурированных данных. Без кода можно скопировать содержимое в чат и попросить показать таблицей. Названия файлов сохраняйте при передаче. Не загружайте готовый разбор вместе с исходниками, если хотите измерить собственное выполнение.
