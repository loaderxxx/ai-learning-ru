# 1. Документы без выдумок

**Результат:** карточка актуальной встречи и таблица изменений с указанием разделов. Ориентир — 30–45 минут. Нужен любой доступный чат; файлы можно заменить вставкой текста.

## Что здесь легко пропустить

Сводка двух документов часто смешивает условия разных версий: время из нового, площадку из старого, отсутствующую ссылку из предположения. Красивое объявление при этом выглядит убедительно. Наша задача — проверить происхождение каждого поля.

Откройте [версию 1](../fixtures/event-v1.md) и [версию 2](../fixtures/event-v2.md). Вторая явно заменяет первую. Правило «более новый файл всегда главный» не универсально: здесь приоритет указан в самом документе. В другой задаче его может потребоваться уточнить у автора.

## Выполните без кода

1. Скопируйте оба текста в чат, отделите их названиями. Если загружаете файлы, сначала попросите перечислить доступные названия и воспроизвести по одному короткому фрагменту из каждого. Сверьте фрагменты сами.
2. Отправьте запрос ниже. Не открывайте разбор заранее.
3. Для даты, времени, формата, числа мест, регистрации, оборудования и записи найдите подтверждающий раздел.
4. Найдите хотя бы один вопрос, на который исходники не дают ответа.
5. Составьте короткое объявление только после проверки таблицы.

```text
Сравни «Мастерская идей — версия 1» и «версия 2».
Сначала установи, какая версия действует и почему.
Составь таблицу: поле, старое условие, новое условие, документ и раздел.
Затем сделай карточку актуальной встречи. Отдельно перечисли неизвестное.
Не добавляй ссылку подключения, имена или условия, которых нет в источниках.
```

Время сохраняйте вместе с часовым поясом. «19:00» без UTC+3 теряет существенную часть условия. Не переводите время старого документа в новый пояс: в старом город и пояс неизвестны.

## Усложнение для разработчика

Попросите ИИ выдать JSON с полями `date`, `time`, `timezone`, `format`, `capacity`, `registration_deadline`, `join_url`, `evidence`. Для отсутствующей ссылки используйте `null`. `evidence` должен содержать название документа и раздел для каждого известного поля.

Напишите проверку структуры, затем отдельно проверьте смысл: совпадение полей с источниками. Валидный JSON может содержать неверное время. Добавьте свою третью версию с одним изменением и проверьте, что старый ответ пересчитан, а не скопирован.

## PDF и сканы — дополнительная ветка

В основном задании текст доступен полностью. На своём учебном PDF сначала выясните, извлекается ли текст, видны ли таблицы и изображения. Поддержка визуального содержимого PDF зависит от режима сервиса; успешная загрузка файла не доказывает полноту чтения. Сравните одну строку таблицы с оригиналом. Если есть только изображение, распознавание и проверка чисел становятся отдельными шагами. См. P01–P02 в [источниках](../SOURCES.md).

## Приёмка

Текущая карточка не содержит очного зала, старого времени и выдуманной ссылки. Неизвестные поля помечены явно. Найдены минимум пять изменений, а неизменившиеся условия не объявлены изменёнными. Сверка — [разбор примеров](../fixtures/ANSWER_KEY.md).

Сохраните [результат](../templates/RESULT.md), включая ошибку первого ответа, если она была. Если ошибок не было, так и напишите; придумывать их не нужно.
